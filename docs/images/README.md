# Thesis figure

`results-page.jpg` is the original embedded JPEG from Figure 5-1, "Result Page for a Completed Run", in the author's final-year thesis. It appears on printed page 38 (PDF page 46) of the submitted thesis.

The image was extracted at its original 2003 x 1601 resolution without resizing, retouching or changing the displayed values. It documents the historical Angular interface, video preview, run metadata and artefact-download controls. It is not a screenshot of the newly added CPU replay or an accuracy evaluation.

The historical run ID differs from the archived sample under `examples/sample_run/`. The existing trajectory image remains in that example folder.
